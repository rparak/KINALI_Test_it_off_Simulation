# Final checklist

Walk it before finishing. Report each item as done, not applicable, or not
verified (with the reason).

## Structure

- [ ] The top block: title, value sentence, real badges, key figure, at most one or two alerts.
- [ ] Sections only where relevant, in the recorded order; nothing padded.
- [ ] Visible part about 150-250 lines (or the project's recorded budget); depth in `<details>`.
- [ ] Contents line lists the visible sections only, and all of them.
- [ ] A blank line after every `</summary>`.
- [ ] A block written by code was regenerated by its command, not edited (structure.md).

## Facts

- [ ] Every number has a unit and a source; estimates and simulation results labelled.
- [ ] Every number that changed is changed everywhere it appears (text, tables, captions, figures).
- [ ] Statuses written identically everywhere.
- [ ] No claim without evidence in the repository; nothing promised.

## Commands

- [ ] Every documented command run as written, on the stated platform; output shown matches.
      System prerequisites: presence check run, install command not run.
- [ ] Commands that write were run into a temporary directory; nothing in the repository changed
      unintentionally (`git status`).
- [ ] Fences have language tags; no `$ ` in copy-paste blocks.

## Figures

- [ ] Generated by the figure script; none edited by hand.
- [ ] Light and dark in a complete `<picture>`, with an explicit width.
- [ ] No title in the image; axes, units, legends, status labels and estimate footnotes present.
- [ ] Alt text of at least 12 words; numbered caption below, in order.
- [ ] Within the size budget (the defaults, or the budgets with reasons in `check_readme.json`).
- [ ] Videos linked as release assets, not committed; `CITATION.cff` tested if it exists.
- [ ] **Looked at**, light and dark, every new or changed image.

## Links

- [ ] Relative links resolve; anchors resolve; no absolute local paths, hosts, IPs or secrets.
- [ ] No link to internal documents the project keeps out of the README.

## Rendering

- [ ] `render_readme.py` (local cmarkgfm) shows no leftover Markdown; GitHub's API only with consent.
- [ ] Mermaid checked with `mmdc`, or flagged for the user to verify after push.

## Tests

- [ ] `check_readme.py`: 0 errors; warnings fixed or listed as judgement calls.
- [ ] The project's README tests run and pass (named in `references/project.md`).
- [ ] `references/project.md` still describes the README (sources, figures, rules, tests).
